# 动作捕捉处理平台

当前版本实现最小闭环：版本化保存原始采集、校准和处理结果；将带缺测与身份交换的人工标记恢复为连续骨架；对过长缺口保留 `unknown`；支持按时间片段修订标记身份并生成受影响的新版本。

## 数据约定

- 采集版本：原始 `Observation(frame, marker, position, confidence)`，只追加，不覆盖。
- 校准版本：保存关节、骨连接、骨段长度、关节角范围，以及来源采集版本。
- 处理版本：保存输出骨架、未知帧、约束警告、身份修订和父处理版本。
- 关节状态：`observed`、`observed_constrained`、`interpolated`、`constrained`、`unknown`。

## 恢复规则

1. 应用指定时间片段内的标记身份映射，原始观测仍可从采集版本读取。
2. 对不超过 `max_short_gap` 的连续缺测做线性填补。
3. 按骨架层级把骨段长度投影到校准值。
4. 在提供关节角上下限时，把父子骨夹角投影到合法范围。
5. 超过阈值的缺口不编造位置，输出 `position=None`、`status="unknown"` 并写警告。
6. 用已知真实动作和恢复结果逐帧计算 RMSE。

## 运行

```bash
python -m unittest discover -s tests -v
python -m mocap.demo
```

演示会构造一段已知手臂动作，加入短暂遮挡、7 帧尾部缺口和 3 帧标记交换。第一版处理保留错误身份；第二版加入 `fix-arm-swap` 修订，只重算指定片段并保留父版本链接。

后续动作分类和导出适配应读取处理版本，不直接改写采集版本或校准版本。
